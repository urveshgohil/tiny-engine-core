Version 1.5.0 DX Upgrade Demo

This page shows how to use the new developer-experience features in this project: debug mode, runtime devtools, and the plugin system with `UI.use(plugin)`.

DX Upgrade
Debug + warnings Turn on `UI.config({ debug: true, warnings: true })` for friendlier development feedback.
Devtools bridge Inspect runtime state with `UI.devtools()` or `window.__TINY_ENGINE__`.
Plugin system Install add-ons with `UI.use(plugin)` to hook create, init, emit, and more.
What this demo uses

One class capsule, one functional capsule, one store with middleware, one plugin, and a live devtools snapshot panel.
