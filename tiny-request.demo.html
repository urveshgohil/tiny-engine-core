Example Import

import { request, TinyRequest, TinyRequestError } from 'tiny-engine-core';

const api = new TinyRequest({
  baseUrl: '/demo-api',
  timeout: 1200,
  headers: { 'x-demo-client': 'tiny-request-demo' }
});
`GET` caching uses the built-in in-memory store, so you can click `Cache GET` twice and compare the network counter.
`Abort Slow Request` uses `key: 'slow-demo'` and then calls `request.abort('slow-demo')`.
`Retry Flaky API` fails twice with status `503` before succeeding, so you can confirm retry behavior.
